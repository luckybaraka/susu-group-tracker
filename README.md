# Susu Group Tracker

A small program that manages one rotating savings group (susu).

In a susu, a group of members each pay the same fixed amount every week. Each
week the whole pot is paid to one member. Members receive the pot in the order
they joined, one member per week.

This project is being built step by step. See the commit history for the stages
of development. Full usage and testing instructions follow as the program grows.
